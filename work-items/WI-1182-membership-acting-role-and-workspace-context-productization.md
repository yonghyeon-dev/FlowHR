# WI-1182: 멤버십 역할 워크스페이스 문맥 제품화

tenant membership, acting role, workspace context 를 UI 언어와 흐름에서 제품 개념으로 정리한다.

## Scope

1. workspace context 표현 통일
2. signed-in account / role / workspace 상태 노출 방식 정리
3. cross-role 흐름에서 문맥 혼선 축소

## Acceptance Criteria

1. 사용자가 현재 어떤 회사 문맥에서 어떤 역할로 일하는지 이해할 수 있다.
2. raw technical claim 없이도 문맥이 전달된다.
3. 계정/세션/product language 가 일관된다.
