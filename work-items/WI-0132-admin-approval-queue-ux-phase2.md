# WI-0132: Admin Approval Queue UX Phase 2

## Background and Problem

`/admin#approvals`는 WI-0128에서 큐 필터/검색/정렬과 기본 모바일 레이아웃을 확보했지만, 운영자가
정체 항목의 긴급도를 빠르게 판단하고 모바일에서 즉시 일괄 처리하기에는 정보 밀도와 액션 접근성이 부족했습니다.
승인 대기 시간을 줄이기 위해 알림 배지 정교화, 검색/정렬 보강, 모바일 조작성 2차 개선을 진행합니다.

## Scope

### In Scope

- 승인 큐 알림 배지 정교화
  - 큐별 긴급/주의/정상 상태 표시
  - 큐별 최장 대기 시간 표시
  - 큐 알림 요약 카드(긴급 대기/주의 대기/최우선 큐)
- 검색/정렬 고도화
  - 검색 범위 선택(전체/직원ID/요청ID/메모·사유)
  - 빠른 필터 토글(긴급만, 선택 항목만, 필터 초기화)
  - 정렬 옵션 확장(정체 우선순)
- 모바일 조작성 개선
  - 선택 항목 대상 `모바일 빠른 승인 액션` 스티키 영역
  - 모바일에서 필터/액션 버튼 가로 폭 확장
- 관련 스타일(`src/app/globals.css`) 갱신
- WI-0132 e2e 회귀 테스트 추가 및 e2e suite 반영

### Out of Scope

- 승인 워크플로 도메인 규칙/상태머신 변경
- 스케줄러/cron/GitHub Actions 추가
- 신규 배달 채널(webhook/email) 확장

## User Scenarios

1. 관리자는 큐 배지와 알림 요약 카드로 긴급 대기 건을 즉시 식별한다.
2. 관리자는 검색 범위와 빠른 필터로 필요한 대기 건만 빠르게 추린다.
3. 관리자는 모바일 화면에서 선택 항목을 스티키 액션으로 즉시 승인/반려한다.

## Data and API Changes

- DB 스키마 변경 없음
- API 스펙 변경 없음
- 관리자 화면 상태 계산/렌더링 로직과 스타일만 확장

## Rollback Plan

- 알림 배지/요약 카드/빠른 필터/모바일 스티키 액션 UI를 제거하고 WI-0128 상태로 복귀
- 계약/API/DB 변경이 없어 프론트엔드 파일 단위 롤백으로 즉시 복구 가능
- Recovery target: 30m

## Definition of Done (DoD)

- [x] 승인 큐 배지에 긴급/주의/최장 대기 정보가 노출된다.
- [x] 검색 범위 선택, 긴급/선택 필터, 정체 우선 정렬이 동작한다.
- [x] 모바일 빠른 승인 액션 바가 선택 항목 기준으로 동작한다.
- [x] WI-0132 e2e 회귀 테스트가 추가되고 스위트에 반영된다.
