# WI-1176: 관리자 급여 신고 문서 레인 완성

payroll, year-end, filing, payslip delivery, receipts, document-operating surfaces 를 한 레인으로 정리해 admin 운영 completeness 를 높인다.

## Scope

1. payroll/finalization/filing/document surfaces 의 visual contract 통일
2. 상태, 경고, conflict, empty, success feedback 공통화
3. admin side 문서/급여 흐름의 route-first completeness 강화

## Acceptance Criteria

1. 급여/신고/문서 surface 가 같은 lane 으로 읽힌다.
2. state feedback 이 공통 패턴으로 보인다.
3. representative payroll/filling routes 가 새 shell 과 자연스럽게 연결된다.
