# WI-1171: 실서비스 전환 프로그램 맵 고정

실서비스 운영 수준까지 가는 작업을 대분류만이 아니라 실제 실행 가능한 WI 묶음으로 재정의하고, 이후 구현이 이 맵을 기준으로 진행되도록 고정한다.

## Background

- 지금까지는 UI/UX 중심 재정립이 진행됐지만, 실제 서비스 완료선까지의 WI 프로그램은 문서 한 곳에 고정돼 있지 않았다.
- 컴팩트 이후 드리프트를 막으려면 대분류, 중분류, 소분류가 WI와 직접 연결된 실행 문서가 필요하다.
- 사용자는 “실제 서비스가 가능할 정도”까지의 계획이 WI 기준으로 먼저 촘촘하게 내려오길 원한다.

## Scope

1. `docs/service-readiness-execution-map.md`를 작성한다.
2. 실서비스 전환 프로그램을 Phase 와 WI 묶음으로 정의한다.
3. 현재 진행 중인 `WI-1170`과 이후 후속 WI의 위치를 맵에 연결한다.
4. `docs/production-operating-progress.md`의 현재 큐를 이 프로그램 기준으로 다시 맞춘다.

## Non-Goals

- 이 WI 안에서 실제 서비스 완료까지 전부 구현하는 일
- 개별 surface 코드를 직접 변경하는 일

## Acceptance Criteria

1. 실서비스 완료 기준이 문서에 명확히 정의되어 있다.
2. 이후 구현이 의존할 WI 묶음이 phase 단위로 정리되어 있다.
3. `WI-1170` 이후의 다음 WI 우선순위가 문서만 보고도 명확하다.
