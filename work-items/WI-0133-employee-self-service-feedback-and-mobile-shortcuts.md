# WI-0133: Employee Self-Service Phase 3 - Request Feedback and Mobile Shortcuts

## Background and Problem

직원 포털은 출퇴근/휴가 요청과 기본 조회 기능을 제공하지만, 요청 처리 결과(대기/승인/반려)와 실패 원인을
직원이 한 번에 파악하기 어렵고 모바일에서 반복 동작으로 이어지는 단축 흐름이 부족했습니다.
요청 상태 피드백을 강화하고 실패 원인을 명확히 보여 주며 모바일 조작 단계를 줄이는 3차 UX 고도화를 진행합니다.

## Scope

### In Scope

- `/employee` 요청 상태 피드백 패널 추가
  - 출퇴근/휴가 상태 요약 카드(대기/승인/반려/취소)
  - 최근 요청 상태 피드백 리스트(채널/상태/메시지)
- 실패 원인 가시화
  - API 실패 응답/반려 사유를 사용자 화면에서 확인
  - 최근 실패 원인 복사 액션
- 모바일 단축 흐름 패널 추가
  - 오늘 출퇴근 입력, 정정 시작, 오늘 반차/내일 하루 신청 단축 버튼
  - 요청 상태 새로고침/피드백 바로가기
  - 단축 동작 결과 피드백 메시지
- 직원 사이드바 네비게이션에 신규 섹션 앵커 추가
  - `#request-feedback`, `#mobile-shortcuts`
- 관련 스타일(`src/app/globals.css`) 추가
- WI-0133 e2e 회귀 테스트 추가 및 e2e suite 연결

### Out of Scope

- 휴가/근태 도메인 정책 규칙 변경
- 백엔드 API/DB 스키마 변경
- 스케줄러/cron/GitHub Actions 추가

## User Scenarios

1. 직원은 요청 상태 피드백 패널에서 최근 처리 결과를 빠르게 확인한다.
2. 직원은 실패 원인 섹션에서 반려/실패 사유를 즉시 파악하고 복사해 문의에 활용한다.
3. 직원은 모바일 단축 버튼으로 반복 입력 과정을 줄여 요청 작업을 빠르게 완료한다.

## Data and API Changes

- DB 스키마 변경 없음
- API 계약 변경 없음
- 클라이언트 상태 계산/표시 로직과 스타일 확장

## Rollback Plan

- 요청 피드백/실패 원인/모바일 단축 패널 및 네비 앵커를 제거하고 WI-0131 상태로 복귀
- 계약/API/DB 변경이 없어 프론트엔드 파일 단위 롤백으로 즉시 복구 가능
- Recovery target: 30m

- [x] 실패 원인 가시화 및 최근 실패 원인 복사 액션이 동작한다.
- [x] 모바일 단축 버튼 흐름과 결과 피드백 메시지가 동작한다.
