# WI-0128: Admin Approval Queue UX Upgrade (Badges, Search/Sort, Mobile)

## Background and Problem

결재/승인 엔진은 확장됐지만 `/admin#approvals` 운영 UX는 대기 목록을 단순 나열하는 수준이라
우선순위 판단과 대량 처리 속도가 떨어집니다. 특히 모바일 화면에서 액션 밀집도가 높아 조작성이 낮습니다.

## Scope

### In Scope

- 관리자 승인 대기함 UX 개선:
  - 큐 포커스 배지(전체/출퇴근/휴가/급여) 추가
  - 검색 입력(직원ID/요청ID/상태/기간) 추가
  - 큐별 정렬 추가
    - 출퇴근: 출근 최신순/오래된순/직원ID순
    - 휴가: 시작일 최신순/오래된순/직원ID순
    - 급여: 기간 최신순/총지급 높은순/직원ID순
  - 검색 결과/선택 카운트 메타 표시
- 모바일 반응형 개선:
  - 승인 패널에서 툴바/리스트/액션 버튼이 세로로 재배치되도록 CSS 추가
- WI-0128 회귀 테스트 추가 및 e2e suite 연결.

### Out of Scope

- 승인 API/상태머신 로직 변경.
- 자동 승인/자동 반려 정책.
- 알림 채널 확장(webhook/email/scheduler).

## User Scenarios

1. 관리자는 큐 배지로 출퇴근/휴가/급여 대기함을 빠르게 전환한다.
2. 관리자는 검색/정렬로 긴 대기열에서 대상 항목을 빠르게 추린다.
3. 모바일에서도 대기 항목 선택/승인/반려 버튼을 겹침 없이 조작한다.

## Data and API Changes

- DB 스키마 변경 없음.
- API 변경 없음.
- `/admin` 클라이언트 렌더링과 CSS 레이어만 변경.

## Rollback Plan

- 승인 큐 필터/검색/정렬 UI와 관련 CSS를 제거하고 기존 리스트 렌더링으로 복귀합니다.
- 서버 계약 변경이 없어 롤백은 프론트엔드 파일 기준으로 즉시 가능합니다.
- Recovery target: 30m.

## Definition of Done (DoD)

- [x] 승인 큐 배지/검색/정렬이 `/admin#approvals`에 반영된다.
- [x] 모바일에서 승인 패널 리스트/액션 레이아웃이 반응형으로 동작한다.
- [x] 기존 승인 액션(개별/일괄)은 기능 회귀 없이 동작한다.
- [x] WI-0128 회귀 테스트가 추가되고 e2e suite에 연결된다.
