# WI-1175: 관리자 운영 레인 롤아웃

attendance, leave, notices, benefits, recruitment, contracts 의 운영 surface 를 같은 operating lane 규칙으로 정리한다.

## Scope

1. operations lane 대표 surface 의 header, summary, queue, detail rhythm 통일
2. notices / benefits / recruitment / contracts 의 entry 와 follow-up 동선 정리
3. 관리자 업무 흐름에서 화면별 밀도 편차 축소

## Acceptance Criteria

1. 대표 운영 surface 가 같은 제품 리듬을 공유한다.
2. 카드 예쁨보다 실제 처리 흐름이 우선된다.
3. representative route pair 검증이 가능하다.
