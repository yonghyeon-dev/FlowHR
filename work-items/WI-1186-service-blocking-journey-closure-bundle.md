# WI-1186: 서비스 차단 여정 클로저 번들

실서비스 전환을 막는 남은 notice, contracts, approvals, payroll, filing, request journey blocker 를 묶어서 닫는다.

## Scope

1. 현재 남아 있는 service-blocking journey 를 재분류
2. 진짜 launch blocker 만 묶어서 follow-up WI 로 연결
3. journey-level acceptance 기준 정리

## Acceptance Criteria

1. 실서비스 차단 여정 목록이 명확하다.
2. blocker 와 polish 가 분리된다.
3. launch gate 직전 재검증 대상을 한 번에 볼 수 있다.
