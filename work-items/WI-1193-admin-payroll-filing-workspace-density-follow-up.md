# WI-1193: 급여 레인 신고 워크스페이스 밀도 후속 정리

## 배경

`WI-1192`로 신고 ops 단계 보드는 급여 레인 시각 리듬에 맞춰졌지만,
메인 신고 워크스페이스(`/admin/payroll-year-end-filing`)는 여전히 입력 패널과 결과 패널의 밀도가 높고
상단 액션 우선순위가 흐릿합니다.

## 범위

1. 메인 신고 워크스페이스의 입력 패널과 결과 패널을 급여 레인 시각 기준으로 다시 정리한다.
2. 핵심 액션과 보조 액션의 위계를 분명히 하고, summary/KPI 카드의 우선순위를 다듬는다.
3. 관련 stale guard가 있다면 같은 WI 안에서 current baseline으로 함께 정리한다.

## 완료 조건

1. `/admin/payroll-year-end-filing`의 상단 구조와 입력/결과 패널 밀도가 현재 급여 레인 기준과 맞는다.
2. 주요 액션이 보조 액션보다 먼저 읽히고, 결과 요약 카드가 현재 상태를 바로 설명한다.
3. 관련 current quality gates가 green이다.
