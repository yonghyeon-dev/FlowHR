# WI-1177: 관리자 급여 문서 상세 후속 정리

## 배경

`WI-1176`으로 `/admin/payroll` 레인을 세웠지만, 급여 문서 상세와 배포 후속은 아직 `payroll-payslip-delivery`, 계약 문서, 신고 상세 사이에 분산되어 있습니다.
다음 파동에서는 급여 레인 안의 문서 상세 진입과 후속 상태 표현을 더 촘촘하게 정리합니다.

## 범위

1. 급여 레인에서 문서 상세 진입점을 더 분명하게 분리한다.
2. 명세서 배포 후속과 계약 문서 후속의 액션 계층을 맞춘다.
3. 필요 시 payroll detail/document follow-up 전용 정적 가드를 추가한다.

## 완료 조건

1. `/admin/payroll`에서 문서 후속 진입점이 명확하게 읽힌다.
2. 명세서/계약/신고 문서 후속의 시각 계층이 동일한 패턴으로 보인다.
3. 관련 current quality gates가 green이다.
