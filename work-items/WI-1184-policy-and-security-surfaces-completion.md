# WI-1184: 정책과 보안 surface 완성

leave policies, attendance security, notification defaults 등 정책형 화면을 운영 제품 수준으로 완성한다.

## Scope

1. policy/security surface 의 CRUD/feedback 구조 정리
2. 관련 settings 와 운영 레인 연결 강화
3. 빈 상태와 recovery guidance 제품화

## Acceptance Criteria

1. 정책형 surface 가 temporary admin tools 처럼 보이지 않는다.
2. 운영자 입장에서 상태와 결과가 명확하다.
3. product language 가 통일된다.
