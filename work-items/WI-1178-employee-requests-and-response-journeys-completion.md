# WI-1178: 직원 요청과 응답 여정 완성

employee requests hub, monitoring, resubmit, attendance, leave 흐름을 하나의 request journey 로 정리한다.

## Scope

1. requests hub / monitoring / resubmit / attendance / leave 간 정보 구조 통일
2. employee request follow-up language 와 response feedback 완성
3. 요청 여정을 document/account 로부터 명확히 분리

## Acceptance Criteria

1. employee 요청 흐름이 분리된 패널 묶음이 아니라 하나의 journey 로 읽힌다.
2. request search, monitoring, resubmit 동선이 명확하다.
3. request CTA 와 feedback 이 동일한 패턴을 쓴다.
