# WI-1190: 관리자 급여 레인 여정 마감

## 배경

`WI-1176`, `WI-1177`, `WI-1189`로 급여 레인과 문서/마감 상세의 source-aware 흐름은 이어졌지만, 아직 급여 레인 전체 여정은 개별 작업면 중심으로 분산되어 있습니다.
이번 후속 WI에서는 급여 레인에서 마감, 배포, 문서 후속으로 이어지는 대표 운영 여정을 한 번 더 맞춥니다.

## 범위

1. `/admin/payroll`에서 진입하는 대표 상세 화면의 배너, 되돌아가기, focus 문구를 같은 운영 문맥으로 정렬한다.
2. 급여 레인에서 문서 후속과 마감 후속 사이의 대표 진입 흐름을 다시 점검하고 끊긴 지점을 제거한다.
3. current quality gates에 급여 레인 여정 회귀 가드를 추가하거나 기존 가드를 보강한다.

## 완료 조건

1. 급여 레인에서 시작한 대표 운영 여정이 generic admin hub로 떨어지지 않는다.
2. 마감, 배포, 문서 후속 화면이 같은 급여 레인 문맥으로 보인다.
3. 관련 current quality gates가 green이다.
