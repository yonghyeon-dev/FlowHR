# WI-1183: 운영 설정 통합

admin 운영 설정을 scattered settings 에서 실제 day-2 운영 콘솔로 묶는다.

## Scope

1. settings group 재정렬
2. notification, escalation, security, feature controls 의 information architecture 정리
3. 운영자가 자주 쓰는 설정 중심으로 우선순위 재구성

## Acceptance Criteria

1. settings 가 실제 운영 콘솔처럼 읽힌다.
2. 설정 찾기 비용이 낮아진다.
3. 대표 설정 surface 가 같은 shell/visual contract 를 공유한다.
